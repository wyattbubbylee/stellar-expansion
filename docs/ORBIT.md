# Orbit dimension: first access prototype

## Survival entry

Craft the **Space Access Beacon** using an Eye of Ender, two obsidian, a compass, and a redstone block:

```
 E
OCO
 R
```

Hold the beacon and right-click in the Overworld to enter `stellar_expansion:orbit`. The first visit creates a 7 x 7 smooth-stone landing platform at (0,128,0). Right-click the beacon again in orbit to return near the Overworld spawn. The item is reusable, with a short cooldown.

## Creative testing

With cheats enabled:

```
/give @s stellar_expansion:space_beacon
```

## Important limitations

- This is an empty prototype dimension: no stars, oxygen, asteroids, or gravity yet.
- The beacon returns to *Overworld world spawn*, not necessarily the precise spot you left.
- The platform is shared by all players.
- Survival safety and interactions with ATM10: Aeronautics have not yet been verified.
- Do not use on a valuable world before the Java code and dimension datapack pass a real game-load test.
