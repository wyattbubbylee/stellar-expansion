# Stellar Expansion

A Minecraft NeoForge 1.21.1 mod project for building custom orbital stations, Dyson megastructures, and automated space industries.

## Planned features

- Mega Launcher: launch custom station modules and cargo into orbit.
- Physical 3D holographic blueprint designer.
- Construction drones and artificial gravity.
- Asteroid mining and automatic orbital cargo shuttles.
- Dyson-first logistics, with inventory reservations and warehouse routing.
- Compatibility targets: ATM10: Aeronautics, standard FE storage, and modded inventories.
- High-detail nearby shuttle visuals with low-end graphics alternatives.

## Status

Early development. This is a project roadmap, **not a playable mod release yet**. NeoForge source, tests, textures, and models will be added progressively. Moving ships, ring gravity and mod integrations need practical testing.
